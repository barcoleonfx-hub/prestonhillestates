Logo files for the homepage concept. `python3 concept/build.py` swaps them in for the text
links automatically. Use exactly these names (PNG, SVG, JPG or WebP):

- tpo.png         The Property Ombudsman
- safeagent.png   safeagent
- prs.png         Property Redress Scheme
- mydeposits.png  myDeposits
- zoopla.png      Zoopla
- onthemarket.png OnTheMarket

Files placed in web/public/portals or web/public/accreditations are picked up too.
